# أكاديمية سينما | Cinematic Educational Platform 🎬🚀

منصة تعليمية متكاملة لتعليم البرمجة الإبداعية وتطوير المواقع ثلاثية الأبعاد بأسلوب سينمائي مبتكر، مستوحاة من المواقع الفاخرة مثل Bassthalk.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

### الواجهة الأمامية (Frontend)
- **React.js + TypeScript + Vite** لسرعة البناء والتشغيل.
- **Tailwind CSS** للتصميم المتجاوب والمستقبلي.
- **Redux Toolkit** لإدارة الحالة الشاملة للمنصة (التحقق، الكورسات، التقدم).
- **GSAP (ScrollTrigger)** للتحريكات والتفاعلات السينمائية فائقة السلاسة.
- **Three.js** لخلفيات الفضاء التفاعلية ثلاثية الأبعاد والمجسمات الطائرة.
- **Lucide Icons** للأيقونات الفاخرة المتناسقة.

### الواجهة الخلفية (Backend)
- **Node.js + Express.js + TypeScript** لبناء واجهة برمجية متطورة (REST API).
- **Prisma ORM** لإدارة قواعد البيانات بيسر وأمان.
- **SQLite Database** لقاعدة بيانات محلية سريعة وخفيفة (جاهزة للتحويل إلى PostgreSQL بضغطة زر).
- **JWT (Json Web Tokens)** لحماية الجلسات وتجديد التذاكر التلقائي (Access + Refresh Tokens).
- **Bcrypt.js** لتشفير كلمات المرور بشكل آمن للغاية.
- **Multer** للتعامل مع رفع الملفات والصور المصغرة.

```bash
├── backend/                  # خادم البيانات وقاعدة البيانات
│   ├── prisma/               # مخطط قاعدة البيانات (schema.prisma) والـ Migrations

│   │   ├── middleware/       # برمجيات التحقق والصلاحيات ورفع الملفات
│   │   ├── routes/           # مسارات الـ API
│   │   ├── utils/            # التشفير وإصدار الرموز الأمنية (JWT, Hash)
│   │   └── server.ts         # ملف تشغيل الخادم الرئيسي
│   └── package.json
│
├── frontend/                 # واجهة المستخدم والمؤثرات البصرية
│   ├── src/
│   │   ├── app/              # إعدادات مخزن Redux Store
│   │   ├── components/       # المكونات المشتركة (Navbar, Footer, Three.js background)
│   │   ├── features/         # شرائح Redux (Auth slice, Courses slice)
│   │   ├── hooks/            # الخطافات المخصصة (useAuth, redux hooks)
│   │   ├── pages/            # الصفحات الأساسية واللوحات (Home, Courses, CoursePlayer, Admin)
│   │   ├── services/         # خدمة Axios للاتصال بالـ API وتجديد التذاكر تلقائياً
│   │   ├── App.tsx           # موجه الصفحات والمسارات المحمية
│   │   └── main.tsx          # نقطة انطلاق التطبيق
│   └── package.json
```

## 🚀 طريقة تشغيل المشروع محلياً (How to Run)

### المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org) (إصدار 18 فما فوق).

### 1. تشغيل الواجهة الخلفية (Backend)
1. افتح موجه الأوامر واذهب إلى مجلد `backend`:
   ```bash
   cd backend
   ```
2. تثبيت الحزم:
   ```bash
   npm install
   ```
3. مزامنة قاعدة البيانات وإنشاء ملف `dev.db`:
   ```bash
   npx prisma db push
   ```
4. بذر قاعدة البيانات بالبيانات الافتراضية (Seed):
   ```bash
   npx ts-node-dev --transpile-only src/seed.ts
   ```
5. تشغيل الخادم في وضع التطوير:
   ```bash
   npm run dev
   ```
   *سيعمل الخادم على الرابط: `http://localhost:5000`*

### 2. تشغيل الواجهة الأمامية (Frontend)
1. افتح نافذة موجه أوامر جديدة واذهب إلى مجلد `frontend`:
   ```bash
   cd frontend
   ```
2. تثبيت الحزم:
   ```bash
   npm install
   ```
3. تشغيل خادم التطوير (Vite):
   ```bash
   npm run dev
   ```
   *ستعمل الواجهة على الرابط: `http://localhost:5173` (أو الرابط المعروض في المخرجات)*
